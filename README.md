## 📱 Panduan Instalasi Android (APK)

1. Unduh file `app-release.apk` dari rilis terbaru.
2. Buka file APK yang telah diunduh di perangkat Android Anda.
3. Jika muncul peringatan keamanan instalasi dari sumber tidak dikenal:
   - Masuk ke **Pengaturan** perangkat Anda.
   - Aktifkan opsi **"Izinkan dari sumber ini"** (Allow from this source).
4. Selesaikan instalasi dan buka aplikasi Atheric.
5. Masuk (*login*) atau daftar akun baru untuk mulai menganalisis pasar saham Indonesia (IDX) dengan AI.
